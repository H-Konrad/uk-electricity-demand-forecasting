## Data

The main historical electricity market and weather data used by the project is stored in PostgreSQL. This folder is used for modelling datasets, sample API responses and model evaluation outputs generated by the project.

### Dataset

Contains the datasets created by the modelling dataset creation script. These files are not included in the repositry. 

They are generated from the data stored in PostgreSQL and include data derived from external sources such as Elexon and Open-Meteo / UK Met Office, which are subject to their own licensing and attribution requirements.

### Responses 

Contains small sample Elexon API responses used to test parsers and parts of the data pipeline.

These files are included in the repository because they are small and allow parts of the project to be tested without repeatedly calling the live API.

### Results

Contains the model performance results.

These files are not included in the repository but are generated and stored here when the relevant scripts are run.
